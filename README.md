# 🍳 Chef Calc
> **Smart Costing, Better Pricing, Higher Profit.** > ระบบบริหารจัดการสต็อกวัตถุดิบและคำนวณต้นทุนอาหารอัจฉริยะ

---

## 📖 Introduction / แนะนำโปรเจกต์
เว็บแอปพลิเคชัน Full-stack ที่ออกแบบมาเพื่อช่วยเชฟและเจ้าของธุรกิจอาหารในการบริหารจัดการวัตถุดิบและคำนวณต้นทุนสูตรอาหารอย่างแม่นยำ ระบบนี้ช่วยลดความผิดพลาดจากการคำนวณด้วยมือ และช่วยให้การวางแผนราคาขายทำได้อย่างมีประสิทธิภาพผ่านข้อมูลเชิงลึก

---

## ✨ Key Features / คุณสมบัติเด่น
* **Precision Costing:** Automated recipe cost calculation with ingredient breakdown.
    * *คำนวณต้นทุนสูตรอาหารอัตโนมัติ พร้อมแสดงรายละเอียดวัตถุดิบรายรายการ*
* **Inventory Management:** Track ingredients, categories, and purchase history.
    * *ระบบจัดการคลังวัตถุดิบ แยกหมวดหมู่ และบันทึกประวัติราคาซื้อ*
* **Dynamic Analytics:** Real-time dashboard showing margins, profit, and performance.
    * *แดชบอร์ดแสดงผลกำไร ส่วนต่าง แบบเรียลไทม์*
* **Responsive UI with Dark Mode:** Fully optimized for all devices with seamless theme switching.
    * *รองรับทุกอุปกรณ์ (Mobile First) พร้อมระบบสลับ Dark/Light Mode*
* **Smart Validation:** Integrated toast notifications for better user feedback and error handling.
    * *ระบบแจ้งเตือน (Toast) และการตรวจสอบข้อมูลเพื่อป้องกันความผิดพลาด*

---

## 🛠️ Tech Stack / เทคโนโลยีที่ใช้
* **Frontend:** React.js, Tailwind CSS, Framer Motion (for animations)
* **Backend:** Node.js, Express.js
* **Database & Auth:** Supabase (PostgreSQL)
* **Utility:** Axios (API), Day.js (Date formatting), React Hot Toast (Notifications), ReChart (Graph)
